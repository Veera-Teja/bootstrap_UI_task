KeshavSoft – Interactive Startup Website

A responsive and interactive startup website developed using HTML, CSS, and Bootstrap 5 as part of the KeshavSoft internship task.

Project Overview

This project focuses on creating a modern website interface with a clean layout, responsive design, and interactive UI elements.

Technologies Used

- HTML5
- CSS3
- Bootstrap 5

Features

- Responsive website layout
- Animated hero section
- Image carousel
- Interactive hover effects
- About page
- Contact page with contact form

How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Navigate through the website pages.
