# KeshavSoft – Midnight Creative Website

A modern, responsive, multi-page website developed using **HTML5, CSS3 and Bootstrap 5** as part of the KeshavSoft internship UI design task.

The website features a premium dark theme with aqua, violet and pink accents, gradient effects, interactive components and responsive layouts.

## Project Overview

The objective of this project is to explore modern frontend development concepts and create an attractive user interface using Bootstrap 5 and custom CSS.

The website includes three connected pages: Home, About and Contact. Each page follows a consistent visual theme with smooth transitions and interactive design elements.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Custom styling, gradients, animations and hover effects
- Bootstrap 5.3.2 – Responsive layouts and UI components
- Bootstrap Icons – Interface icons
- JavaScript – Carousel functionality, contact form interaction and dynamic footer year
- Google Fonts / System Fonts – Typography
- Unsplash – External website images

## Website Features

### 1. Home Page

- Modern dark-themed navigation bar
- Gradient hero section with highlighted text
- Aqua and violet gradient buttons
- Bootstrap image carousel with three slides
- Automatic carousel transitions and navigation indicators
- Feature cards with hover-lift effects
- Responsive layout for different screen sizes

### 2. About Page

- Modern About section with gradient heading
- Team collaboration image
- Custom dark-themed information cards
- Research and execution sections
- Responsive Bootstrap grid layout

### 3. Contact Page

- Modern contact form interface
- Name, email, subject and message fields
- Required-field validation
- Client-side success message
- Responsive form layout

**Note:** The contact form is a frontend demonstration. It does not send or store messages on a server.

## How to Run the Project

1. Clone or download this repository.
2. Extract the project folder.
3. Open the folder in Visual Studio Code.
4. Make sure all HTML pages and `style.css` are in the same directory.
5. Open `index.html` in your web browser.
6. Navigate between Home, About and Contact pages.

An active internet connection is required for the Bootstrap CDN, Bootstrap Icons and externally hosted images.
